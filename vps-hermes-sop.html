Hostinger VPS Ubuntu 22.04 Tailscale Mesh Docker 一键部署 Hermes Desktop 7×24 在线
Step 01
购买 VPS，选择 Ubuntu 系统
在 Hostinger 用折扣码 WOWINSIGHT 注册，选购最便宜的套餐。
操作系统选 Ubuntu（建议选带 Docker 预装的模板），选离你最近的节点。
# Hostinger 官网 https://hostinger.com/WOWINSIGHT # 推荐选：Ubuntu 22.04 LTS (Docker 预装模板) # SSH 登录后记录 IP 地址备用
Step 02
安装 TMUX（保持会话常驻）
TMUX 让你的命令行会话在本地关机后依然保持运行。
同时解决 Hermes 启动时的中文乱码问题。
$ apt update && apt install tmux -y
Step 03
Docker Manager 一键部署 Hermes
在 Hostinger 后台左侧 Docker Manager 搜索 Hermes，点击第一个「Hermes Agent」部署。
部署完成后，穿透进容器内部。
# 肉身穿透进容器（容器名可能不同，用 docker ps 确认） $ docker exec -it hermes-agent-tndl-hermes-agent-1 bash # 首次进入后输入 hermes 回车，按提示免费注册官网账号 # 选择 NVIDIA 免费模型开始体验
Step 04
安装 Tailscale（组建加密内网）
必须装在 VPS 宿主机上，不要装进 Docker 容器里。
Tailscale 在 VPS 和家里设备之间建立加密隧道，让你像访问本地局域网一样操控远程 VPS。
# 安装 Tailscale（注册：https://tailscale.com 免费） $ curl -fsSL https://tailscale.com/install.sh | sh # 启动并认证（会输出一个魔法链接，复制到浏览器打开） $ tailscale up # 复制输出的 https://login.tailscale.com/a/xxxxxx 链接 # 粘贴到浏览器完成认证
Step 05
iptables MSS 调优（丝滑流式输出）
这条规则守在 Docker 网桥和 Tailscale 网卡的交界处，把 TCP 最大报文段大小（MSS）裁剪到 Tailscale 的 1280 字节规格。
有了它，Hermes 的流式吐字（Streaming）才能真正丝滑，不会被切碎丢包。
$ iptables -I FORWARD -p tcp --tcp-flags SYN,RST SYN -j TCPMSS --clamp-mss-to-pmtu
Step 06
固定容器端口（防止端口漂移）
Docker 每次重启端口会随机变化，导致 Hermes Desktop 每次都要重新配。
在 Hostinger 后台 Projects → 编辑 docker-compose.yml，把 ports 写死为 "32768:4860"。
# docker-compose.yml 关键片段 services: hermes-agent: image: ghcr.io/nousresearch/hermes-agent:latest ports: - "32768:4860" # 固定端口，重启不变
Step 07
配置 extra_hosts（注入内网节点）
在 extra_hosts 里把家里 Tailscale 节点的名字和 IP 写死，让云端 Hermes 能直接呼叫家里的智能体。
# docker-compose.yml 中加入 extra_hosts services: hermes-agent: extra_hosts: - "99:100.120.136.28" - "bobo:100.120.136.175" - "mechanic-01:100.120.136.99" # 请替换为你自己 Tailscale 网络里的真实 IP
Step 08
注入 SOUL.md（给 AI 安装灵魂）
把编辑好的 SOUL.md 强行塞进容器，让云端 Hermes 认识自己是分布式网络的一部分，知道 99、bobo、mechanic-01 都是可调用的邻居节点。
# 把容器内的 SOUL.md 复制到宿主机（先查看文件名） $ docker ps # 找到你的容器名 $ docker cp hermes-agent-tndl-hermes-agent-1:/opt/data/SOUL.md ./SOUL.md # 编辑 SOUL.md（参考下方「参考文件」章节） $ nano ./SOUL.md # 塞回容器并重启 $ docker cp ./SOUL.md hermes-agent-tndl-hermes-agent-1:/opt/data/SOUL.md $ docker restart hermes-agent-tndl-hermes-agent-1
Step 09
验证 & 连接 Hermes Desktop
重启后穿透进容器，问它：「你知道 99、bobo 和 mechanic-01 是什么吗？」
如果它能准确回答，说明灵魂注入成功。最后在 Hermes Desktop 里配置 Remote Gateway 连接到 VPS。
# 穿透进容器测试 $ docker exec -it hermes-agent-tndl-hermes-agent-1 bash hermes$ 你知道 99、bobo 和 mechanic-01 是什么吗？ # Hermes Desktop 连接方式： # 齿轮 → Gateway → Remote Gateway # 输入 VPS 的 Tailscale IP + 端口 32768 # 用户名/密码：安装 Hermes 时设置的凭证

参考文件

直接复制使用，替换 IP 为你自己的 Tailscale 节点地址。

docker-compose.yml
version: '3.8'
services:
  hermes-agent:
    image: ghcr.io/nousresearch/hermes-agent:latest
    container_name: hermes-agent-vps
    ports:
      - '32768:4860'
    extra_hosts:
      - '99:100.120.136.28'
      - 'bobo:100.120.136.175'
      - 'mechanic-01:100.120.136.99'
    restart: unless-stopped
